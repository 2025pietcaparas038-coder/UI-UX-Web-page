# A Little Something for You ✿

A cute, mobile-friendly friendship surprise website built with plain HTML, CSS, and JavaScript. No libraries, accounts, backend, or build tools required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Try the questions, mystery clue, and final reveal.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository**, for example `little-surprise`.
2. Upload `index.html` to the repository's root (the top level). You may also upload this README.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. The Pages section will show a website address similar to:
   `https://YOUR-USERNAME.github.io/little-surprise/`
7. Open that address to test it on your phone, then send the link to your friend on WhatsApp.

## Personalize it
Open `index.html` in VS Code or any text editor. Search for:
- `Hey,` to change the welcome text.
- `Just a reminder that you're appreciated.` to change the main reveal.
- `your friend, who made this little corner...` to change the sign-off.

## Privacy note
The website has no analytics, server, or external dependencies. Her answers are held only in the open browser tab and are not uploaded or sent anywhere. Anyone with the published link can view the page, so do not put private details in it.


## Digital friendship scrapbook
The site includes a photo-free interactive scrapbook based on the real story: Class 9 academic rivals, becoming friends in Class 10, and a supportive friendship today. Open the site and choose **Preview the scrapbook** on the welcome screen.

The scrapbook also includes a playful **Chudel & Bandar Chronicles** page based on the friends' nickname joke (the user started calling her Chudel, and she calls him Bandar).
